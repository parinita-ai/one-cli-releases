# One CLI releases

Release files for **One CLI** (`one`), the One coding agent for the terminal,
by Denizen Blu LLC: binaries for macOS, Linux and Windows, checksums, and the
Linux packages.

- **Install:** the install script, Homebrew and apt/dnf all download from this
  repository's releases.
- **Updates:** `one upgrade` checks this repository's latest release and verifies
  its checksum before replacing the binary.

This repository holds release files only. The source is private; nothing here
is meant to be edited by hand, and releases are published by CI.
